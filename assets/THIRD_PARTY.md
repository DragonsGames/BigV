## Google Material Icons Round

Source: https://github.com/google/material-design-icons

License: Apache License 2.0. The complete license text is stored at
`licenses/material-icons-APACHE-2.0.txt`.

The following source glyphs were exported as transparent 128 px PNGs and
recolored with BigV's blue-violet brand gradient or semantic state colors:

- `verified` -> `bigv_verify.png`
- `check_circle` -> `bigv_success.png`
- `error` -> `bigv_error.png`
- `warning` -> `bigv_warning.png`
- `lock` -> `bigv_lock.png`
- `key` -> `bigv_code.png`
- `help` -> `bigv_help.png`
- `badge` -> `bigv_role.png`
- `tag` -> `bigv_channel.png`
- `build` -> `bigv_repair.png`

No font, icon library, or remote asset is loaded by the running bot.
